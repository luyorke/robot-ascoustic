# 投稿可行性审查与理论升级方案（2026-10-16）

## 1. 现行 CIPHER（theory.md v0.3）的审查结论

目标期刊：IEEE TSP（重理论）/ IEEE TIM（重测量系统与实验）。

| 拟定贡献 | 审稿人可能的判断 | 依据 |
|---|---|---|
| 定理 1：跨阵元相位与钟差/同步无关 | **平凡**。同步采样阵列内的相位差与发射端时钟无关是干涉测向的常识 | 相位干涉仪 / PDOA 文献 |
| 定理 2：中心对称阵列丢弃共同相位无方位信息损失 | 已知结论（相位参考取阵列质心时方位与公共相位解耦） | DOA CRB 经典分析 |
| 多基站位姿域耦合消栅瓣 | 本质是 DPD（直接定位，Weiss 2004 起）+ 未知朝向的刚体版本 | Weiss/Amar DPD 系列 |
| TDOA 门控 + ratio test | GNSS 标准做法的迁移 | LAMBDA / ratio test |
| 镜像源时延域多径模型 | 多径辅助定位（虚拟锚点）已有成熟体系 | Leitinger/Witrisal 等 |
| 距离–多普勒耦合、上/下扫解耦 | 雷达教科书内容（三角 FMCW）；DRAPE、PALM 已在声学中使用 | — |
| 波前采样像差 1/(1+β) | 运动阵列补偿的已知效应 | 声呐阵列运动补偿 |
| 口径–模糊折中 | 有价值但偏数值，缺少闭式结论 | — |

**结论**
- **TSP：现行版本不够。** 每个部件都有先例，整体是一个工程上做得很细的组合，缺少一个"非它不可"的新原理。
- **TIM：有机会，但有硬伤。** 实测若能达到 5–10 mm / 0.05°，已比 DRAPE（3.6 cm）、SCALA（2.15 cm）好约 4 倍，符合 TIM 的口味；但 (a) 精度强烈依赖阵元标定：每颗麦克风 5° 相位误差 → 16–18 mm，(b) 每帧 7 s 的 Python 计算量与"实时测量系统"不符，(c) 仿真器与估计器共用同一物理模型，审稿人会质疑。
- 仿真结果本身是可信的，但"只用阵元间相位"这一设计选择把最强的信息扔掉了（见 §2）。

## 2. 关键发现：声学载波的周期是 50 μs

之前的决策（PROGRESS §4，2026-10-15）是"基站同步残差 μs 级，跨基站整周固定不可靠"，所以只用阵元间相位。这个判断套用了射频的直觉，在声学中不成立：

- 射频（2.4 GHz）载波周期 0.4 ns，载波级同步需要 ps 级——做不到；
- **声学（20 kHz）载波周期 50 μs，1 μs 同步残差只相当于 7.2° 相位、0.34 mm 距离。**

也就是说，**μs 级无线同步的声学基站，本身就已经是"载波相位同步"的基站。** 跨基站的绝对载波相位（类似 GNSS 的载波相位 TDOA）可以直接使用，几何基线是房间尺度（≈10 m），而不是阵列口径（0.1 m）。

### 2.1 数值核算（线性化 CRLB，200 个随机位姿，4 基站，脚本见 scratchpad `idea_xanchor.py / idea_c.py / idea_amb.py`）

每颗麦克风相位噪声取 0.61°，使"只用阵元间相位"的 CRLB 与 exp01 的 2.0 mm 对齐：

| 方案 | 位置 CRLB | 航向 CRLB | 每颗麦克风 5° 固定相位误差 → 位置偏差 |
|---|---|---|---|
| 现行 CIPHER（阵元间相位） | 2.04 mm | 0.0091° | **16.3 mm** |
| + 跨基站载波相位，同步 0.5 μs | 0.20 mm | 0.0089° | 0.21 mm |
| + 跨基站载波相位，同步 1 μs | 0.38 mm | 0.0089° | **0.72 mm** |
| + 跨基站载波相位，同步 2 μs | 0.72 mm | 0.0090° | 2.4 mm |
| + 跨基站载波相位，同步 10 μs | 1.76 mm | 0.0091° | 12.4 mm |
| + 跨基站，同步 1 μs，**声速未知一并估计** | 0.58 mm | — | 声速估计 ±0.05 m/s（≈0.08 °C） |

- 位置精度提高 3–10 倍；**对阵元相位误差的敏感度降低约 20 倍**（基线放大比 ≈ 距离/口径）→ 位置几乎不再依赖麦克风标定；
- 航向仍由阵列决定（不变）；
- 声速必须联合估计（0.1% 声速误差会造成最远角落 11 mm 的距离差误差），代价小，系统同时成为声学温度计；
- 存在交叉点：同步残差 ≳ 10–20 μs 时跨基站项失去作用，自动退化为现行 CIPHER。

### 2.2 整周模糊度

跨基站载波相位有整周未知数（每个基站一个，λ≈17 mm）。分级固定：

1. 包络 TDOA（cm 级）→ 排除远处假峰（现有门控）；
2. 阵元间载波相位（现行 CIPHER，mm 级）→ 作为"中间车道"给出浮点距离；
3. 跨基站载波相位整周固定（ILS / ratio test）。

单历元 bootstrapping 成功率（同步 1–2 μs）：

| 阵列解精度 | 浮点模糊度标准差 | 单历元成功率（中位 / 最差） |
|---|---|---|
| CRLB 噪声 | 0.13 周 | 1.000 / 0.98 |
| 2 倍（≈ CIPHER 仿真实测） | 0.25 周 | 0.95 / 0.75 |
| 4 倍（≈ 实板标定后） | 0.50 周 | 0.58 / 0.38 |

连续跟踪时整周数保持不变（帧间距离变化由帧内速度估计预测，误差 1–2 mm ≪ λ/2），多历元累积后成功率迅速提高 → 需要约 1 s 的收敛时间（待仿真验证）。

## 3. 新理论框架（暂名 CIPHER-X：从时钟免疫到载波同步的统一估计）

**核心命题**：同步残差 σ_s 与载波周期之比决定信息结构。
- σ_s ≫ 1/(2πf_c)·(ρ/R) 量级：跨基站载波相位无信息，最优估计 = 时钟免疫的阵元间相位（现行 CIPHER）；
- σ_s ≪ 该量级：跨基站载波相位主导位置，阵列只负责航向与模糊度固定；
- 统一似然：直达径复增益的相位与 t0 绑定，c_{i0} = |c_{i0}| e^{−j2πf_c(t_rx + d_i/c + ε_i) + jφ_i}，ε_i ~ N(0, σ_s²) —— 在现有时延域模型上只改这一处。

**可写成定理/命题的内容（对 TSP 有分量）**
1. 交叉点定理：给出位置 Fisher 信息随 σ_s 的闭式过渡，交叉点 σ_s* 与 R/ρ、f_c、M 的关系（"声速慢 → 宽松同步即载波同步"的定量表述）；
2. 敏感度定理：阵元相位误差 δχ 对位置的影响在两种区间分别为 O(ρ/R)·λδχ 与 O(1)·λδχ；
3. 声速可观性：4 个以上基站 + 阵列航向约束时 (p, t_rx, c) 可辨识，并给出 GDOP 型界；
4. 分级模糊度固定成功率界：以阵列解协方差为浮点解的 ILS 成功率（Teunissen bootstrapping 界），给出阵列口径/基站数的设计准则。

**需要正视的风险**
- 空气温度梯度与湍流使各路径声速不同（不是一个公共 c），可能把实际精度限制在亚 mm–mm；
- 基站喇叭（压电，谐振 20 kHz）的相位随温度漂移 → 每基站相位常数需标定并监测；
- 基站播放起始时刻必须由硬件定时器触发并锁定到同步计数器（软件中断的抖动会直接变成相位误差）；
- 遮挡导致的周跳需要检测与重新固定；
- 直达径绝对相位仍受未建模多径影响，但对位置的放大系数从 ~70 降为 ~1。

## 3.5 原型验证（2026-10-16，`sim/cipher/carrier.py`，静止、混响、同步 2 μs，16 位姿 × 2 帧）

实现：CIPHER 解出后，取每个基站直达径复增益的相位作为载波时刻 → 以 CIPHER 位姿/协方差和 t_rx 为先验，搜索每个基站 ±1 周的整周组合，最小二乘解 (x, y, t_rx, s) → 差值检验 → 航向按协方差相关随位置更新。每基站相位常数 b_i 用 4 个已知位姿（动捕）标定。

| 观测 | 结果 |
|---|---|
| 载波时刻精度（对真值） | 每基站常数偏差 + 0.1–0.45 μs 抖动（0.03–0.15 mm）→ 观测本身极精确 |
| 浮点整周误差 | 约 0.2 周/基站：位置先验 0.10–0.15 周 + CIPHER t_rx 0.155 周 |
| 声速已知（σ_s = 0.01%） | 最优候选 31/32 帧误差 0.14–1.42 mm，1 帧整周错（14.6 mm）；通过差值检验的 69% 帧 **0.83 mm**（同帧 CIPHER 1.84 mm），接近 CRLB 0.72 mm |
| 声速先验 ±0.3% | 错误整周可被声速变化补偿 → 区分度不足，固定率 9% |
| **模型声速偏 0.3%（≈0.5 °C）** | **CIPHER 本身从 3.5 mm 退化到 21 mm**（同步约束以 μs 精度比较 10 m 量级距离）——此前所有仿真都假设声速已知，这是新发现的风险；已在 `LagFit` 中加入声速参数（`estimate_c`，默认关闭待验证） |

结论：方向成立——整周固定正确时位置精度提高约 4 倍并接近 CRLB。瓶颈是 (1) 声速必须跨帧持续估计（它以分钟尺度变化），(2) 整周需要跨帧保持与验证（GNSS 式），单帧固定不够可靠。

## 3.5b 多帧载波跟踪器的关键发现（2026-10-16，`carrier.CarrierTracker`）

| 发现 | 量化 | 对理论/实现的含义 |
|---|---|---|
| 声速必须进入**完整**几何（含镜像径），不只是同步项 | 只放同步项：0.3% 声速误差下仍 22 mm；放入完整几何：3.46 mm（与声速准确时相同），单帧声速估计 ±0.017% | 多径模型使声速单帧可观——"声学温度计"是 CIPHER 的副产物 |
| 单帧整周固定在原理上不足 | 4 基站 4 个方程对 (x, y, t_rx[, s])，冗余 ≤1；运动中 CIPHER 位置协方差 ~7 mm | 必须多帧（GNSS 式） |
| 决定固定成败的是**声速精度**，不是基站数 | 线性化：声速 ±0.3% → 单帧 66%、20 帧 83–97%；声速 0.01% → 单帧 92%、5 帧 100%；6 基站无改善 | 定理候选：整周可固定性由 s 的先验精度主导 |
| 载波观测量要在脉冲峰处读相位 | 读法错误时运动中偏 0.6 周；修正后运动中对真值 0.004–0.01 周 | 载波相位跟踪 chirp 中心历元，免疫距离–多普勒耦合（引理的直接应用） |
| "公共平移别名"：t_rx 移一个平均周期 + 全部整周 +1 | 各基站失配仅 +6/+2/−2/−5 μs（FDMA 宽巷） | 区分度 ∝ (失配/σ_s)²；σ_s ≲ 2–3 μs 时可分 → 交叉点定理的具体形式 |
| CIPHER 的包络级 t_rx 有 20–30 μs 位姿相关偏差 | ≈半个周期 | 不能用作 t_rx 先验；帧间 t_rx 必须由基站固定帧周期 + 窗口内钟漂参数绑定 |
| 载波读法的 β² 二阶项（符号随扫频方向） | 2 m/s 时 0.13–0.21 周 → 修正后 0.004–0.009 周 | 由模板精确扣除（theory §11）；是 2 m/s 捕获失败的根因 |
| 帧间整周传递（时间差分载波相位） | 用"上一帧最优位置 + 多普勒速度"预测：36 帧中仅 0–3 次单基站跳周 | — |
| 标定常数必须用公共声速 | 单帧声速噪声 0.02% × 25 ms 传播时间 = 5 μs | 标定中声速与 b_i 联合估计 |

单条轨迹（0.5 m/s，声速偏 0.3%，σ_s 2 μs）：第 7 帧（0.7 s）固定后全程保持，误差 0.18–1.48 mm（同帧 CIPHER 1–9 mm），χ²/观测 ≈ 0.6。

## 3.5c exp07 结果（正式实验）

见 PROGRESS §5：模型声速偏 0.3%、σ_s 在线自估时，固定帧精度 0.92/0.85/1.55 mm（0.5/1/2 m/s），为同帧 CIPHER 的 1/4–1/5；零错误固定；同步 10 μs 时 σ_s 自估 10.5 μs 并自动保持 CIPHER（交叉点行为得到验证）。

## 3.5d 长时间运行与遮挡（exp08 第一版，2026-10-17）

30 s 轨迹，事件：8–10 s 基站 1 直达径 −25 dB；15–15.5 s 基站 3 静默；22–23 s 基站 0、2 同时被挡。
- 单基站遮挡/掉线：CIPHER-X 维持约 1 mm、整周不丢（逐基站残差 4σ 剔除 + 恢复后在亚毫米解处取整重固定）。
- **双基站同时遮挡：CIPHER 本身跳到错误的瓣（220 mm），恢复慢；CIPHER-X 未察觉，继续"固定"并输出 200 mm 误差。**
- 尝试过的同步残差 RAIM 无效（声速作为自由参数后，4 基站同步约束无冗余，残差恒为 0）——已撤回；每基站未解释能量显示双遮挡失败是整体错瓣，而非单个坏基站。
- 修正：(B) **载波辅助跟踪**——CIPHER-X 固定解作为 CIPHER 下一帧先验（`track(aid=...)`）；(C) 保持期**新息检验**——CIPHER 位置与载波预测矛盾（Mahalanobis² > 25）时不作先验，只剩 2 个基站时允许"载波 + 运动预测"滑行 ≤ 1 s。重跑中（CIPHER 单独与 CIPHER-X 在同一信号上对照）。
- 附带发现：基站 3 在无遮挡时未解释能量也有 −9…−15 dB（高 SNR 残余失配，PROGRESS §6 第 3 项）。
- 工程：长时间运行内存泄漏（每帧保留拟合对象与多普勒模板）已修复：`track()` 改为生成器、脉冲模板裁剪到可用时间段并用 LRU 缓存。

**exp08 最终版**（完好性规则迭代 4 轮后）：见 PROGRESS §5 表格。迭代教训：(1) 滑行 + 拒绝 CIPHER 先验会把错误固定自我确认，必须保持 CIPHER 作为独立检验；(2) 均值相干度在遮挡下会误触发失锁，改用去掉最差基站的稳健相干度；(3) 运行中冷启动需两帧门控；(4) σ_s 超限后仍需持续估计，否则死锁；(5) 失锁后声速状态回退到 CIPHER 级不确定度；(6) 错误整周可自洽地偏 10–20 mm，单帧新息检验发现不了，需"窗口平均新息"检验。

## 3.5e 去除最后一处真值依赖（2026-10-17）

- 此前所有仿真的帧窗口起点都由仿真真值（接收钟差 δ、钟漂 η）算出——实测中不可得。新增 `pipeline.frame_starts`：只用前端首径检测，捕获第一帧后以一阶环路把最早到达保持在窗口内 5 ms 处。验证：钟漂 30 ppm 时与真值窗口结果一致（CIPHER 4.21 vs 4.34 mm，CIPHER-X 固定帧 0.86 vs 0.85 mm）；钟漂 300 ppm、未知钟差时窗口仍正确（单元测试）。
- 在 300 ppm 下发现符号错误：CIPHER 的 η 是"等效多普勒"（快时钟使信号像远离的声源一样被拉伸，η_CIPHER = −钟频偏），载波级把它当成钟频偏使用 → 帧间 t_rx 链接每帧错 2η·T_f。修正后 300 ppm 时 CIPHER-X 固定率 0% → 56%（固定帧 1.30 mm）；30 ppm 时基本不变（窗口解自行估计 η）。
- CIPHER-X 实验（exp07/08/10/11）改为全部使用自主帧定时，最终重跑。

## 3.6 论文主线与模块分层（2026-10-16）

唯一主线：**声速慢 → μs 级同步的声学基站即"载波相位同步"；异步稀疏阵列因此可做 GNSS 式分级载波相位定位（包络 → 阵元间相位 → 跨基站相位），阵列负责航向与整周固定，跨基站相位负责位置。**

| 层级 | 模块 | 论文中的位置 |
|---|---|---|
| 核心贡献 | 交叉点/敏感度定理；分级整周固定（阵列 = 中间车道）；声速联合可观性；载波跟踪器（声速 + 整周保持 + σ_s 自估，合为一个模块） | 理论 + 主实验 |
| 必要观测模型 | 时延域多径模型、运动/多普勒模型、棋盘波形 | 一节"测量模型"，各给消融数字 |
| 工程细节 | 标定流程、首径回溯、噪声底、门控等（theory §6.6） | 实验节 / 附录 |

准入准则：新模块必须直接服务主线并有消融数据证明不可缺。
附带叙事：载波相位跟踪 chirp 中心历元时延，天然不受距离–多普勒耦合影响（只有包络受影响）。
