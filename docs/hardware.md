# 硬件分析：WB-SD2008-V1.1 八麦克风圆阵

来源：`cad/WB-SD2008-V1.1.pdf`（原理图 + PCB 顶视图）、`cad/WB-SD2008-V1.1.SLDPRT`（SolidWorks 2023，PCB 导出后"另存为零件"）。
尺寸由 SLDPRT 内嵌 Parasolid 几何（单位 m）与 PDF 矢量坐标交叉验证得到。

## 1. 机械几何（已确认）

| 项目 | 数值 | 依据 |
|---|---|---|
| 板形 | 圆环 | PDF/SLDPRT |
| 内径 / 外径 | 90.0 mm / 113.7 mm（R 45.000 / 56.859） | Parasolid 圆半径，PDF 比例 1.2635 一致 |
| 板厚 | 1.59 mm | Parasolid z 坐标 |
| 安装孔 | 8 个，R = 50.0 mm，方位 22.5° + k·45° | Parasolid 46.194 = 50·cos22.5° |
| 麦克风封装中心 | 8 个，**R ≈ 50.0 mm**，方位每 45° 一个 | PDF 比例 0.19449 mm/pt × 257.1 pt |
| 麦克风编号（PDF 顶视图） | U1 在 90°（上），顺时针 U2 45°、U3 0°、U4 −45°、U5 −90°、U6 −135°、U7 180°、U8 135° | PDF 第 2 页 |

即 `θ_k = 90° − 45°·(k−1)`，k = 1..8（**待确认 PDF 是顶视还是底视，底视则手性相反**）。

相邻阵元间距 = 2R·sin(22.5°) = 38.3 mm；最大口径 100 mm。
在 18–20 kHz（λ ≈ 17–19 mm）下相邻间距 ≈ 2λ ⇒ **严重空间欠采样**：单频相位 DOA 存在栅瓣/整周模糊，必须靠宽带信息或模糊度固定。

### 待确认 / 不确定项
- 麦克风声孔相对封装中心偏 0.77 mm（规格书：声孔距长边端 0.98 mm，长 3.50 mm），朝内还是朝外未定 ⇒ 声孔半径 50 ± 0.77 mm。需实物或标定确认。
- PDF 中每个麦克风外有 Ø5.73 mm 圆（灰色层，疑似结构开孔/禁布）以及 R = 54.45 mm 处 Ø3.16 mm 的编号圆。

## 2. 电路（已确认）

- 8 × **LinkMems LMD3526T261-OAC03**，顶部开孔 PDM 数字 MEMS 麦克风，3.50 × 2.65 × 1.15 mm，声孔 Ø0.5 mm。
- 每颗 100 nF 去耦，VDD = 3.3 V。
- 两两共用 CLK/DATA（PDM 立体声复用），通过 4 个 6-pin FPC（P1–P4, HC-FPC-05-20-4RLTAG）引出：

| FPC | 总线 | L/R=VDD | L/R=GND |
|---|---|---|---|
| P1 | DMIC_CLK1 / DMIC_DATA1 | U1 | U2 |
| P2 | DMIC_CLK2 / DMIC_DATA2 | U3 | U4 |
| P3 | DMIC_CLK3 / DMIC_DATA3 | U5 | U6 |
| P4 | DMIC_CLK4 / DMIC_DATA4 | U7 | U8 |

FPC 引脚：1 = 3.3V，2 = GND，3 = DATA，4 = CLK，5/6 = 固定脚接 GND。
⇒ 主控需提供 **4 路 PDM 数据输入**（每路双沿采样得 2 通道），共 8 通道；4 路 CLK 应来自同一时钟源以保证通道间同步。

## 3. 麦克风规格（LMD3526T261-OAC03-DM1 规格书 v1.2）

- 灵敏度 −26 dBFS @94 dB SPL，SNR 62 dB(A)，AOP 120 dB SPL。
- 时钟：标准模式 1.3–4.8 MHz（典型 2.4 MHz），低功耗 150–900 kHz。
- 时序：SEL=VDD 的通道在 CLK 一个沿后输出，SEL=GND 在另一沿输出（T_DV 40–100 ns）。
- **频响仅标到 20 kHz**，约 16–17 kHz 有 +15 dB 谐振峰，10 kHz 以上偏差 +1…+7 dB。
  ⇒ 近超声 17–22 kHz 位于谐振峰附近，幅相响应陡变，**通道间幅相一致性需要标定**；20 kHz 以上响应未知，需实测。
